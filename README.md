# MindShift AI 🧠

> An intelligent AI-powered recovery coach that helps users overcome addictive habits through personalized behavioral analysis, adaptive coaching, and context-aware recovery guidance.

---

## 📌 Overview

MindShift AI is a modern web application designed to support individuals struggling with addictive habits such as:

- Social Media
- Gaming
- Smoking
- Alcohol
- Pornography
- Procrastination
- Other unhealthy habits

Unlike traditional habit trackers, MindShift AI understands **why** users struggle by analyzing their behavioral patterns and delivering personalized recovery recommendations.

The application combines deterministic behavioral analysis with AI-powered reasoning to create an adaptive recovery experience.

---

# 🎯 Challenge Vertical

**AI-Powered Behavioral Wellness & Habit Recovery Assistant**

MindShift AI acts as an intelligent recovery companion that understands user behavior, predicts potential relapse risks, and provides personalized interventions.

# 🧠 AI Workflow

The application follows a hybrid decision-making approach.

```
User Input
      │
      ▼
Behavior Analysis
      │
      ▼
Risk Calculation
      │
      ▼
Context Building
      │
      ▼
AI Processing
      │
      ▼
Personalized Guidance
```

Rather than acting as a generic chatbot, the AI receives structured behavioral context to generate highly personalized recommendations.
